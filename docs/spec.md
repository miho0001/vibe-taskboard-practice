# 仕様書

タスクボードの現在の仕様。**振る舞いを変えたら、この文書も同じ PR で更新する。**

## 画面

1画面のみ（トップページ `/`）。

| 要素 | 内容 |
| --- | --- |
| 入力欄 | ラベル「タスク名」。プレースホルダ「やることを入力」 |
| 追加ボタン | ラベル「追加」 |
| 絞り込みボタン | 「すべて」「未完了」「完了」の3つ。選択中のものが反転表示 |
| サマリー | 「未完了: N 件」 |
| 一覧 | チェックボックス + タスク名 + 編集ボタン + 削除ボタン |
| 編集中の行 | 入力欄（ラベル「タスク名を編集」）+ 保存ボタン + キャンセルボタン |
| 空表示 | 対象が0件のとき「タスクがありません」 |

## 振る舞い

### タスクの追加

- 入力欄に文字を入れて「追加」を押すと、一覧の末尾に追加される
- 前後の空白は取り除かれる
- 空文字・空白のみの場合は追加されず、「タイトルを入力してください」を表示する
- 追加に成功すると入力欄はクリアされる

### 完了・未完了の切り替え

- チェックボックスで切り替える
- 完了したタスクは打ち消し線とグレー表示になる
- 「未完了: N 件」は未完了のタスク数を表す

### 絞り込み

- 「すべて」: 全件
- 「未完了」: `done === false` のみ
- 「完了」: `done === true` のみ
- 絞り込みは表示だけを変え、データは削除しない

### タイトルの編集

- 各行の「編集」ボタンを押すと、その行がタイトルの入力欄（ラベル「タスク名を編集」）に切り替わる
- 入力欄には現在のタイトルが初期値として入り、フォーカスが当たる
- 編集中の行はチェックボックス・編集ボタン・削除ボタンを表示しない
- 「保存」で確定する。前後の空白は取り除かれる
- 空文字・空白のみの場合は保存されず、「タイトルを入力してください」を表示する。入力欄は開いたままで、元のタイトルが保たれる
- 「キャンセル」で編集をやめると、入力内容は捨てられて元のタイトルの表示に戻る
- 編集で変わるのはタイトルだけ。完了状態・作成日時・並び順は変わらない
- 同時に編集できる行は 1 つだけ

### 削除

- 各行の「削除」ボタンで、その行のタスクだけを削除する

### 保存（永続化）

- タスク一覧はブラウザの localStorage に保存される（キー: `vibe-taskboard:tasks`）
- 追加・完了の切り替え・タイトルの編集・削除のたびに保存され、リロードや再訪問しても内容が保たれる
- 絞り込み条件（すべて／未完了／完了）は保存しない。リロードすると「すべて」に戻る
- 保存データが壊れていた場合（JSON として読めない・形が違う）は、その内容を捨てて空の一覧で起動する。エラー画面や真っ白な画面にはしない
- localStorage が使えない環境（プライベートブラウジング等）では保存されないが、その回の操作は普通に行える

### 表示幅（レスポンシブ）

- スマホからデスクトップまで、横スクロールが出ないことを保証する（確認の基準は幅 375px）
- 長いタイトルは折り返して表示する。空白を含まない文字列（URL や連続した英数字）も途中で折り返す
- タイトルが長くても、チェックボックス・編集ボタン・削除ボタンは縮んだり画面外に出たりしない
- 幅 480px 以下ではカードの余白を詰め、画面の端に貼り付かないように左右に余白を残す

## 現在の制限（未実装）

- 保存先はブラウザごと。別の端末・別のブラウザとは共有されない（サーバーは無し）
- 複数ユーザー・ログインの概念はない
- 編集できるのはタイトルのみ。期限や担当者といった項目は持たない
