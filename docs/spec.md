# 仕様書

タスクボードの現在の仕様。**振る舞いを変えたら、この文書も同じ PR で更新する。**

## 画面

1画面のみ（トップページ `/`）。

| 要素 | 内容 |
| --- | --- |
| 入力欄 | ラベル「タスク名」。プレースホルダ「やることを入力」 |
| 追加ボタン | ラベル「追加」 |
| 絞り込みボタン | 「すべて」「未完了」「完了」の3つ。選択中のものが反転表示 |
| サマリー | 「未完了: N 件」 |
| 一覧 | チェックボックス + タスク名 + 削除ボタン |
| 空表示 | 対象が0件のとき「タスクがありません」 |

## 振る舞い

### タスクの追加

- 入力欄に文字を入れて「追加」を押すと、一覧の末尾に追加される
- 前後の空白は取り除かれる
- 空文字・空白のみの場合は追加されず、「タイトルを入力してください」を表示する
- 追加に成功すると入力欄はクリアされる

### 完了・未完了の切り替え

- チェックボックスで切り替える
- 完了したタスクは打ち消し線とグレー表示になる
- 「未完了: N 件」は未完了のタスク数を表す

### 絞り込み

- 「すべて」: 全件
- 「未完了」: `done === false` のみ
- 「完了」: `done === true` のみ
- 絞り込みは表示だけを変え、データは削除しない

### 削除

- 各行の「削除」ボタンで、その行のタスクだけを削除する

## 現在の制限（未実装）

- リロードすると消える（永続化していない）
- 複数ユーザー・ログインの概念はない
- タスクの編集（タイトル変更）はできない
